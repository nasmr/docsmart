# 0004 First three document types

Status: Proposed
Date: 30 September 2026
Decided by: (founder, design partner)

## Context

Build plan §10 asks which documents the first build slice supports.

## Decision (proposed)

1. **D12 Portfolio creation resolution.** Every value comes from records, so it proves the foundations with no AI (milestone M1).
2. **D1-SP Subscription agreement for a portfolio.** Highest volume, no AI, and it proves composition from the umbrella subscription terms and the portfolio supplement, plus batch assembly (M3).
3. **D13 Portfolio supplement.** The core project document, and the one where AI drafts the issuer description and risk factors (M3 for the template, M4 for AI sections).

First-pass templates for all three, with variants, are in `templates/first-pass/`.

## Consequences

- Side letters (D2) are the recommended next document after this slice, because they carry the highest legal cost per document for sponsors.
- The umbrella subscription terms (U3) are needed before D1-SP can be assembled, and are not yet drafted.

## Open points

- Whether a design partner needs a different document sooner.

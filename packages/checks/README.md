# Checks engine

**Build plan block:** B6  
**Milestone:** M2  
**Status:** Not started

## What goes here

Deterministic checks on an assembled version: missing or invalid slots, broken cross-references, defined terms, contracting-party wording, references to other portfolios, retired templates, and the state of referenced documents.

## Rules this code must hold

- Severities live in the policy store.
- Blocking checks can only be fixed, not overridden by the sponsor.
- No check is ever skipped silently.
